# KODEX−∞ Kinetic Grammar

Status: `PROPOSED CANONICAL DESIGN SYSTEM / V0.1`

## Principle

Motion is a semantic layer. It must communicate the entity's state, ontology, memory and relationship to the observer.

> A form does not move because the interface is alive. The interface appears alive because motion reveals a change in state, relation or memory.

## Motion dimensions

Every preset specifies:

- `direction` — inward, outward, orbital, axial, branching, sectional;
- `tempo` — ambient, responsive, event, transition;
- `amplitude` — micro, local, structural;
- `persistence` — immediate, trailing, remembered;
- `symmetry` — radial, bilateral, axial, broken, emergent;
- `causality` — autonomous, user-reactive, state-driven, memory-driven;
- `resolution` — continuous, stepped, staged, discrete;
- `energy` — dormant, aware, engaged, open, integrating, returning.

## Temporal scale

```text
MICRO       80–300 ms    interface confirmation, focus and local signal
SHORT       300–1200 ms  activation, reveal and state change
MEDIUM      1.2–4 s      organism response and local transformation
AMBIENT     4–30 s       breathing, orbit, drift and memory field
NARRATIVE   path-based   growth, mutation, return and consequence
```

These ranges are starting constraints, not universal rules.

## Primary verbs

### BREATHE

Meaning: latent life, readiness, low-energy continuity.

Avoid: large scale pumping or constant attention capture.

### ROTATE

Meaning: observation, alignment, cyclic relation or axis.

Avoid: arbitrary spinning with no center or state.

### PULSE

Meaning: signal transmission, recognition or state confirmation.

Avoid: using pulse as a generic glow loop.

### ORBIT

Meaning: relational hierarchy around an attractor.

Avoid: all bodies sharing one speed or identical phase.

### GROW

Meaning: temporal accumulation, emergence and irreversible development.

Avoid: scaling a finished tree from zero and calling it growth.

### ROOT

Meaning: grounding, ancestry, dependency and hidden memory.

Avoid: decorative branching without source or consequence.

### SCAN

Meaning: observation, classification and layer reveal.

Avoid: fake metrics or diagnostic authority.

### FEEDBACK

Meaning: the image receives traces of its previous state.

Avoid: uncontrolled accumulation that destroys legibility.

### COLLAPSE

Meaning: convergence, compression, threshold crossing or loss of form.

Avoid: sudden disappearance without transition evidence.

### REASSEMBLE

Meaning: return, memory-derived reconstruction and transformed continuity.

Avoid: simply reversing the entrance animation.

## Lifecycle mapping

### DORMANT

- minimum movement;
- no urgent glow;
- input acknowledged only as proximity;
- no path decision.

### AWARE

- organism orients toward input;
- local signal increases;
- semantic controls become discoverable.

### ENGAGED

- direct interaction changes local structure;
- the user action is reversible until committed.

### OPEN

- the primary transformation is visible;
- a declared memory write may occur.

### INTEGRATING

- the organism stabilizes the consequence;
- related nodes or exits update.

### RETURNING

- previous traces become visible;
- movement is path-derived rather than a generic reverse.

## Input rules

- pointer movement may control parallax, orientation or atmosphere;
- click, tap, keyboard or explicit dwell commits meaningful actions;
- touch must not depend on hover;
- audio is opt-in and modulates signal, never claims semantic interpretation;
- reduced motion removes continuous transformation but preserves state change;
- passive input never silently assigns a path.

## Transition grammar

| Transition | Semantic use | Typical visual mechanism |
|---|---|---|
| CONVERGE | enter threshold or compress state | radial collapse |
| DISSOLVE | release fixed form | mask, particles or line breakup |
| ORBITAL_HANDOFF | transfer attractor | shared center / phase shift |
| GROWTH_TRANSFER | relation becomes continuation | branch or root extension |
| SCAN_REWRITE | change observation layer | sweep and replacement |
| FEEDBACK_RECURSION | memory transforms image | ping-pong buffer |
| SECTION_COLLAPSE | terrain becomes diagram | slicing and flattening |
| REASSEMBLE | Return generated from trace | path-dependent reconstruction |

## Surface treatment limits

Glow, grain, scanlines, chromatic separation and glitch are surface treatments. They may reinforce state but cannot substitute for structural movement.

Rules:

- glow follows emission or activation;
- glitch indicates instability, corruption or transition;
- grain remains below content legibility thresholds;
- scanlines belong to observation or device contexts;
- chromatic split remains local and state-dependent;
- feedback must retain a decay path.

## Reduced motion

Reduced motion is not a blank still.

Use:

- discrete state frames;
- opacity and contrast changes;
- short non-spatial reveals;
- static diagrams with highlighted relations;
- manual step controls;
- textual state labels.

Avoid:

- continuous zoom;
- large parallax;
- radial collapse;
- repeated rotation;
- uncontrolled feedback.

## Review checklist

For every organism ask:

1. What entity is represented?
2. What is its primary verb?
3. What state changed?
4. What user action caused it?
5. What memory is written?
6. What later consequence becomes possible?
7. Does reduced motion preserve that meaning?
8. Is the animation still legible without glow and texture?

If these questions cannot be answered, the motion remains an experiment rather than active product logic.
