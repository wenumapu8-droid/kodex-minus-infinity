# KODEX−∞ SYMBOL SYSTEM

Status: `CANONICAL SYMBOL STANDARD / V0.1`

## Principle

A KODEX symbol is an interface or information element with declared origin, meaning and permitted use. It is not visual filler.

## Origin classes

```text
KODEX_ORIGINAL
UNIVERSAL_UI
TECHNICAL_NOTATION
CULTURAL_SOURCE
MYTHOPOETIC_REFERENCE
```

`CULTURAL_SOURCE` requires attribution, context, permission status and human review.

## Existing symbol families

### Archive

Function: record, preserve, compare versions and expose provenance.

Avoid: implying that restricted information is a collectible secret.

### Eye / Observe

Function: inspection, attention and active source tracing.

Avoid: surveillance threat unless the actual experience concerns surveillance.

### Portal / Threshold

Function: consent, entry, choice and change of state.

Avoid: using the portal as the same central composition in every scene.

### Tree / Roots

Function: lineage, dependency, temporal branching and memory.

Avoid: claiming a specific sacred cultural meaning without source and permission.

### Serpent

Possible KODEX-original functions: continuity, transformation, transmission and non-linear path.

Requires special cultural review when connected to Indigenous or mythological traditions.

### Infinity

Function: continuation, recursion, re-entry and the technical/public mark `−∞ / +∞`.

Avoid: presenting mathematical infinity as proof of spiritual claims.

### Signal / Wave

Function: real or declared synthetic temporal signal.

Avoid: fake ECG, EEG, audio, frequency or telemetry.

### Node / Relation

Function: entity, connection, path and topological position.

Certainty must remain visible.

## Visual construction

- prefer simple geometric systems capable of SVG reuse;
- create optical rather than purely mathematical balance;
- support monochrome and one-color use;
- maintain recognizable silhouettes at small sizes;
- define active, latent, selected, unavailable and reduced-motion states;
- avoid excessive detail in interface glyphs;
- document stroke expansion before manufacturing or large-format use.

## Accessibility

Symbols supporting actions require:

- text label or accessible name;
- visible focus;
- state not encoded by color alone;
- adequate target size;
- no unexplained symbolic-only critical controls.

## Current asset source

A reported `KODEX SVG Pack v1` contains original geometric redraws for logo, symbol, UI, navigation, panels, status, data, signals, motifs, textures, sprite and tokens. It remains migration-pending until bytes and provenance are recovered.

## Canon admission

A symbol becomes canonical only when:

- origin is known;
- meaning is defined;
- visual and accessibility states exist;
- cultural/rights review is complete;
- it is used consistently in at least one approved experience or module.
