# KODEX RETURN ENGINE

Status: `CANONICAL SPECIFICATION / V0.1`

## Principle

> RETURN IS NOT REPETITION. RETURN IS TRANSFORMATION CARRYING MEMORY.

Return is the convergence layer. It restores ordinary orientation, reveals path consequences, exposes provenance and opens continuation.

## Entry requirements

Return may occur at any time for safety or agency. Full semantic convergence additionally requires:

- at least one node encountered;
- a meaningful decision when available;
- source/provenance access;
- a valid session-memory snapshot;
- fallback-safe controls.

## Required sequence

```text
1. REDUCE UNRESOLVED HIGH-PRIORITY MOTION
2. RELEASE OR MUTE AUDIO
3. RESTORE ORDINARY TIME, DATE/CONTEXT AND CONTROLS
4. WIDEN THE FIELD FROM OBSIDIAN TOWARD WHITE
5. REVEAL THE PATH AND ITS CONSEQUENCES
6. EXPOSE SOURCES, METHODS, LIMITATIONS AND UNRESOLVED QUESTIONS
7. GENERATE THE PATH ARTIFACT
8. OFFER CONTRIBUTION, CODE AND SHARING
9. OFFER A CONNECTED NEW ENTRANCE
```

## Visual transformation

```text
OBSIDIAN → OPEN WHITE
FRAGMENT → RELATION
CONTAMINATED SIGNAL → PURE SPECTRUM
DENSE OVERLAY → SPATIAL CLARITY
CONSUMPTION → CONTRIBUTION
```

The spectral field is generated from actual path categories or state accents when possible. It is not an unsupported aura reading.

## Inputs

- session memory;
- evidence and source manifest;
- unresolved questions;
- selected path grammar;
- accessibility and motion settings;
- artifact renderer availability.

## Outputs

```yaml
return_output:
  path_summary: {}
  source_manifest: []
  limitations: []
  unresolved: []
  artifact: {}
  contribution_options: []
  code_options: []
  share_options: []
  re_entry_options: []
```

## Artifact grammar

OBSERVE commonly produces:

- relation constellation;
- evidence map;
- comparison dossier;
- observed field portrait.

REMEMBER commonly produces:

- memory topography;
- temporal organism;
- archive sediment;
- path palimpsest.

The artifact encodes actual path events and includes a provenance manifest.

## Grounding and ordinary orientation

The Return interface presents:

- current controls and exit;
- ordinary interface context;
- natural breathing option;
- visible session completion state;
- no forced closing ritual.

If the contemplative module was used, the system invites the user to notice the room and next physical action. It does not interpret the experience.

## Re-entry

A re-entry option must be connected and new:

- unopened source related to a traced relation;
- unresolved contradiction;
- connected entity not yet explored;
- alternate OBSERVE/REMEMBER path;
- code or method behind the artifact.

## Failure behavior

If artifact rendering fails, Return still provides:

- textual path summary;
- sources;
- limitations;
- contribution route;
- re-entry.

## Prohibited behavior

- declaring enlightenment, healing or transformation as measured fact;
- presenting white/spectral color as proof of raised frequency;
- forcing social sharing;
- hiding source limitations behind the artifact;
- producing an identical artifact for every path;
- using Return as a simple homepage redirect.
