# KODEX OPEN SOURCE ENGINE

Status: `CANONICAL SPECIFICATION / V0.1`

## Purpose

Expose selected code, methods, schemas and examples so KODEX can be inspected, learned from and extended without surrendering private, restricted or commercially protected layers.

## Public candidates

- evidence and claim schemas;
- semantic-passport schema;
- experience graph format;
- accessibility utilities;
- selected SVG glyphs and interface primitives;
- selected Canvas and shader examples;
- source and method documentation;
- contribution templates;
- reproducible path-artifact examples.

## Protected or separate layers

- KODEX marks and signature identity;
- private conversation exports;
- rights-unclear references;
- restricted cultural knowledge;
- client-specific implementations;
- private strategy and pricing;
- licensed fonts, audio and visual assets;
- unreleased commercial engines.

## Repository presentation

Every public module should include:

```text
README
LICENSE or explicit rights notice
SOURCE / METHOD
EXAMPLE
FALLBACK
ACCESSIBILITY
PROVENANCE
CHANGELOG
```

## Code inspection from Return

The user may open:

- the algorithm behind the current visualization;
- the source fields used;
- the transformation ledger;
- the relevant module repository path;
- a minimal runnable example;
- contribution instructions.

## Licensing boundary

A public repository is not automatically permission to reuse. Until a formal license matrix is approved, files retain the rights notice stated in the repository README or file header.

Future license separation should distinguish:

- open-source code;
- public documentation;
- trademarks and identity;
- artwork and media;
- third-party material;
- commercial engine licenses.

## Prohibited behavior

- publishing secrets or private data;
- including third-party artwork merely as a demo asset;
- distributing fonts without permission;
- claiming code is open source without a license;
- presenting generated examples without provenance;
- making the public version intentionally misleading or unusable to force purchase.

## Return contribution

The engine converts curiosity into method access, download, issue creation, code contribution or a related commercial license inquiry.
