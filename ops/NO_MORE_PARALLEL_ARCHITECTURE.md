# NO MORE PARALLEL ARCHITECTURE DURING V0

Status: `ACTIVE GOVERNANCE RULE`

Until the tangible vertical slice is reviewed, agents must not create:

- another canonical journey;
- another complete design system;
- another unrelated runtime stack;
- duplicate scene engines;
- duplicate source/claim/session models;
- another public-wall concept;
- additional repositories without an independent lifecycle need;
- broad new visual packages not assigned to a current issue.

New ideas go to the private warehouse or backlog. They do not interrupt KOD-19 through KOD-22.

Allowed exceptions:

- a blocking correction supported by implementation evidence;
- an accessibility or safety requirement;
- a rights/privacy issue;
- a measured performance constraint;
- a direct dependency required to complete an accepted issue.

The current task is execution, not redefinition.
