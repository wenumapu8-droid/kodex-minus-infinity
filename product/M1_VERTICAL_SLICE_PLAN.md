# KODEX−∞ M1 — Vertical Slice Plan

Status: `CREATOR REVIEW / STACKED ON ADR-0011`

Deployment: `BLOCKED`

## Purpose

M1 proves that the site architecture, node semantics, session memory and Organism Engine can operate as one system without implementing all 25 coordinates.

The slice is not a miniature linear website. It is a connected, stateful subset of the A–Y field.

## Canonical invariants preserved

```text
A = −∞ / common origin / Threshold
M = Heart / 0 / optional distributed depth
Y = Return / +∞ / route-derived convergence
```

- Every completed test journey begins at A.
- M is optional and may appear zero or more times.
- Every completed test journey reaches Y.
- Intermediate coordinates are not traversed alphabetically.
- Loops and mutated revisits are required.
- Y derives from the actual event trace.
- Safe exit remains available at every coordinate.

They also connect at least three semantic worlds while preserving the distinction between project canon, authored interpretation and evidence-linked material.

## Node Recipe contract

The machine-readable registry is:

```text
data/m1-vertical-slice-node-recipes.json
```

Its schema is:

```text
schemas/node-recipe.schema.json
```

Each recipe declares:

- coordinate and assignment status;
- concept statement and question;
- epistemic status;
- world relations;
- sources, activators, provenance, rights and cultural status;
- entry conditions and semantic exits;
- optional M portal conditions;
- meaningful actions and memory writes;
- revisit mutation;
- organism family, preset, renderer and fallback where applicable;
- spectral contribution;
- Return contribution;
- keyboard, touch, reduced-motion, motion-off and non-visual equivalence.

## Runtime sequence

```text
SESSION MEMORY
→ EDGE RESOLVER
→ NODE RECIPE
→ PAGE / EDITORIAL COMPOSITION
→ ORGANISM PRESET
→ COMMITTED ACTION
→ MEMORY WRITE
→ NEW AVAILABLE FIELD
→ Y TRACE COMPOSITE
```

The Organism Engine receives semantic state. It does not independently decide navigation, Heart access or Return eligibility.

## Required delayed consequence

The first delayed-consequence test is:

```text
B / isolate echo
→ C / inspect the corresponding trace
→ B′ / echo returns as a stable filament
→ Y / records the selection and its later consequence
```

This proves that the archive remembers relations across pages rather than merely preserving screen state.

## Required M behavior

M must be demonstrated from at least two regions:

```text
B → M@MACHINE / SIGNAL → B′
H → M@COSMOLOGY → H′
C → M@MEMORY → C′
K → M@MEMORY / ARTIFACT → K′
```

M returns the visitor to the exact previous coordinate, focus, local state and route anchor. It does not rank, diagnose or infer emotion.

## Required Return behavior

Y must derive and display:

- visited coordinates;
- visit counts and mutations;
- committed actions;
- selected and ignored signals with later consequences;
- traced relations;
- opened sources and unresolved provenance;
- spectrum encountered;
- M visit status without judgment;
- current growth stage;
- a deterministic route artifact manifest;
- re-entry options.

Y is not a generic ending animation.

## Eight QA trajectory signatures

The registry defines eight reproducible signatures covering:

1. complete route without M;
2. contextual M and exact anchor restoration;
3. delayed signal echo and mutated revisit;
4. M approached from cosmology;
5. archive → signal → orbit cross-world movement;
6. growth redirected to provenance and restored;
7. multiple contextual M visits;
8. post-Y re-entry while preserving the prior artifact.

These signatures are validation fixtures, not visitor-facing route choices.

## Implementation order

### Gate 1 — Canonical review

- approve or revise the Node Recipe schema;
- approve, move or reject candidate coordinates B, C, H and K;
- confirm the first visual activator for C and the asset packet for K;
- confirm that H represents the first ORBITAL implementation target.

### Gate 2 — Logic laboratory

Implement a noindex graph-runtime lab that proves:

- A entry;
- state-dependent exits;
- committed-action memory;
- M availability from multiple regions;
- exact anchor restoration;
- loop and mutated revisit;
- Y eligibility and trace-derived output;
- deterministic reset and re-entry.

The logic lab may use textual or static visual representations before every organism adapter exists.

### Gate 3 — Organism binding

Bind:

- A to `threshold-portal`;
- B to `signal-vortex`;
- C to an approved FIELD source;
- H to the ORBITAL adapter;
- K to the GROWTH adapter.

M and Y remain contextual composites rather than being forced into a single organism family.

### Gate 4 — Evidence and QA

Record:

- canonical validator output;
- Astro build result;
- desktop and Android screenshots;
- keyboard and touch traces;
- reduced-motion and WebGL-off traces;
- resource disposal evidence;
- eight trajectory manifests;
- creator review decisions.

M1 is complete only when:

- Node Recipe assignments are creator-approved;
- the logic lab passes all eight trajectory signatures;
- FIELD and VORTEX are validated;
- ORBITAL and GROWTH run through the shared host;
- M restores exact route anchors;
- Y generates different outputs from different event traces;
- provenance and epistemic status remain inspectable;
- mobile, keyboard, touch, reduced-motion and static modes are complete;
- no public route is replaced without a separately reviewed integration decision.
