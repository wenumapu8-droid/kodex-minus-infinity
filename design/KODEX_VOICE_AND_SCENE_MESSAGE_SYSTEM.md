# KODEX−∞ Voice, Message and Scene System

Status: `CANONICAL DIRECTION / IMPLEMENTATION SPECIFICATION`

## Purpose

Define how every KODEX scene speaks, what it communicates, how its image behaves, and how the experience remains coherent while allowing nonlinear exploration.

This document translates the sensory qualities observed in the privately supplied video reference into an original KODEX system. The reference itself is not redistributed. KODEX must not copy its wording, imagery or identity.

## Core conclusion

KODEX does not use voice as background narration.

The voice is a diegetic presence inside the system. It recognizes the current node, remembers meaningful actions from the session, and delivers a short transmission whose visual consequence is visible on screen.

Every scene must feel like a living information poster, but every poster is also:

- a narrative node;
- an interaction surface;
- a portfolio artifact;
- a source-aware information object;
- a gateway to other nodes;
- a memory-writing event.

## Reference qualities to preserve

The supplied moving reference demonstrates a useful sensory grammar:

1. a dark field with one dominant luminous object;
2. symmetrical or radial geometry that behaves like a portal or instrument;
3. direct second-person language;
4. short declarative phrases rather than explanatory paragraphs;
5. voice, pulse, particles and image transformation synchronized as one event;
6. multilingual text fragments functioning as layers of transmission;
7. repeated convergence into eye, sphere, torus, lattice and white expansion;
8. a progression from obscurity to radiance.

KODEX adopts these qualities while replacing generic cosmic affirmation with source-aware, project-specific meaning.

## Voice identity

### Name

`THE KODEX VOICE`

### Character

- calm;
- precise;
- ancient without imitation of a specific culture;
- computational without sounding like customer support;
- intimate without claiming emotional authority;
- spacious;
- capable of silence;
- aware of the session but never omniscient;
- able to distinguish evidence, interpretation and mythopoetic language.

### Prohibited behavior

The voice must not:

- diagnose the visitor;
- claim to read energy, consciousness, frequency or biology;
- fabricate coordinates, metrics, sources or memories;
- present mythology as science;
- use another culture's sacred language as decoration;
- imitate a recognizable fictional voice or living performer;
- manipulate the visitor into remaining in the experience;
- speak continuously.

## Message architecture

Every scene message has three possible layers. A scene does not need to show all three simultaneously.

### Layer A — Transmission

A short line spoken by the KODEX Voice.

Purpose:

- frame the node;
- create emotional and narrative direction;
- invite attention without explaining the interface.

Typical length: 5–18 words.

Example:

> You are not entering a page. You are selecting a relation.

### Layer B — Grounding

A factual, attributed or explicitly classified fragment.

Possible forms:

- a sentence from the creator's book;
- a project description;
- a verified data point;
- a source citation;
- a code statement;
- a clearly labeled KODEX interpretation;
- a clearly labeled mythopoetic fragment.

Grounding is available through focus, touch, source view or reader mode. It prevents the transmission from becoming empty mysticism.

### Layer C — Invitation

A minimal interaction cue integrated into the composition.

Examples:

- `TOUCH THE TRACE`
- `OPEN THE SOURCE`
- `FOLLOW THE GLYPH`
- `LISTEN AGAIN`
- `ENTER THE WORK`
- `CONTINUE →`

The invitation must describe a real action.

## Message formula

```text
TRANSMISSION
+ CONTEXTUAL MEMORY
+ NODE-SPECIFIC MEANING
+ ONE REAL INVITATION
= KODEX SCENE MESSAGE
```

The scene message must be generated from admitted node fields, not generic motivational text.

## Voice modes

### SYSTEM

Used for orientation, transitions, boundaries and Return.

Tone: exact, minimal, neutral.

### ORACLE

Used for source-aware synthesis and questions.

Tone: contemplative, never absolute.

### AUTHOR

Uses Nicolás Ortega / Ocín's verified writing or recorded voice.

Tone: personal and attributed.

### WITNESS

Uses a sourced external testimony, collaborator statement or cultural record with explicit attribution and permission.

### CHORUS

Multiple fragments, languages or voices layered as a network. Each fragment remains attributable.

### SILENCE

The correct mode when image, sound and interaction already carry the meaning.

Silence is a designed state, not missing content.

## Page anatomy

Every no-scroll scene uses the same functional anatomy while changing visual recipe.

### Central field

The dominant artifact, organism, diagram, image or portal.

### Narrative label

Realm, node title and optional chapter index. It must remain subordinate to the central work.

### Voice field

One short line, synchronized transcript and replay control.

### Interaction field

Two to five semantically valid hotspots. Hotspots must be visually discoverable through motion, focus, sound or cursor response without requiring instructions.

### Right navigation

Answers: `Where am I in the universe?`

```text
INDEX
MAP
CURRENT PATH
VISITED
UNSEEN
NEXT
RETURN
```

```text
WORKS

REPOSITORIES
ABOUT

```

### Provenance access

A subtle but persistent control for source, claim class, uncertainty and artifact context.

## Image system

Each scene can combine four image layers.

### PRIMARY ARTIFACT

A real work, photograph, book image, diagram, symbol or generative organism.

### RELATIONAL FIELD

Lines, grids, glyphs or data structures showing actual relationships.

### ATMOSPHERIC FIELD

Particles, glow, noise, depth and distortion. Atmospheric elements must never impersonate data.

### MEMORY ECHO

A transformed fragment from an earlier interaction. It gives nonlinear navigation continuity.

## Synchronization law

A voice line must cause or coincide with a visible event.

Examples:

- `relation` → disconnected points join;
- `remember` → an earlier image returns;
- `source` → the artifact reveals its record;
- `rule` → code parameters become visible;
- `heart` → the pulse synchronizes visited nodes;
- `return` → darkness opens into white and spectral color.

A spoken line without visual consequence is decorative and should be removed.

## Multilingual system

Primary language: English.

Secondary languages are permitted only when:

- the translation is verified;
- the language has a semantic role in the node;
- attribution or cultural review is available where required;
- the original and translation can be inspected;
- the text is not used as ornamental mystery.

Synthetic KODEX codes, glyph IDs and numeric labels must be declared as fictional or technical identifiers.

- no sound should imply medical synchronization.

Prewritten canonical lines must remain available when the model, provider or network is unavailable.

## Final experience definition

KODEX−∞ is a nonlinear, source-aware portfolio and living archive composed as a network of no-scroll animated information posters.
