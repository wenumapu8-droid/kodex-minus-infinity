# KODEX Collage Assembly — Agent Entrypoint

This is the operational front door for any agent building KODEX from the Atlas,
Ocín's portfolio, Drive, GitHub, Linear or an iMac Context Vault handoff.

## First query, then inspect

1. Describe the scene job in literal terms.
2. Resolve it through `assets/capability-router.json`.
3. Search `assets/reference-map.json` and `assets/collage-source-index.json`.
4. Open pixels only for the shortlisted creator-owned or reference records.
5. Choose a receiver recipe and the smallest viable runtime.
6. Write a derivative record with source lineage, rights, fallback and scene use.

## Collage packet

Every assembly packet must name:

- canonical scene and narrative job;
- source record IDs, never only filenames;
- layout primitive and receiver recipe;
- motion state (`full`, `reduced`, `off`);
- desktop/mobile/fallback behavior;
- rights and visibility status;
- derivative output and back-reference;
- measurable acceptance evidence.

## Truth rules

- `indexed` means an agent can select the item from metadata and connect it to a
  recipe. `inventoried` means only its existence and location are verified.
- A creator-owned source remains private until its visibility is reviewed.
- A social screenshot is a decomposition reference, never a production asset.
- The iMac is not queried remotely. Its local state enters through KOD-37
  Context Vault handoffs, preserving secrets and local history.
- No agent may invent missing graph nodes, silently settle canonical conflicts,
  fabricate telemetry or present metaphor as scientific evidence.
