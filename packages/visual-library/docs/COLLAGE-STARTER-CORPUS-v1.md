# KODEX Collage Starter Corpus v1

This packet turns the 16 control references into eight composable layers. It is a build brief, not permission to publish the attached images.

## Agent start

1. Select one `layer.*` job from the JSON manifest.
2. Resolve each `sourceId` in `assets/reference-map.json`.
3. Use creator-owned records as canonical direction and external records only as decomposable mechanics.
4. Build the smallest stack listed for the layer.
5. Deliver full, reduced-motion and static fallback states.
6. Record the derivative, source lineage, rights decision and measurable evidence.

## Composition law

The first visible slice should combine journey field, Signal Vortex and glyph grammar. Editorial archive, data taxonomy, deep memory and living specimens enter as independent modules, not as a single overloaded canvas.

The persistent visual grammar is black space, mineral white, controlled ultraviolet, thin technical geometry, editorial typography and truthful telemetry. Motion communicates state change; it is not wallpaper.

## Rights boundary

- Canon files are creator-owned sources, but public release still requires a reviewed derivative record.
- Tool screenshots document capabilities only.
- External creature, guardian, interface and diagram references are reference-only.
- Cultural and scientific claims keep their dedicated gates.
- No original is overwritten, bulk-published or silently reclassified.

## Definition of done

A layer is assembly-ready only when its semantic source IDs, interaction, runtime, mobile behavior, reduced-motion state, static fallback, rights decision and acceptance evidence are all present.
