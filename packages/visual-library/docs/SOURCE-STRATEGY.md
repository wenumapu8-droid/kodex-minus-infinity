# Source strategy

Search and acquisition are separate steps.

## Preferred order

1. Procedural SVG/Canvas geometry generated inside KODEX.
2. Public-domain scientific and museum collections.
3. CC0 assets.
4. CC BY assets with visible attribution.
5. Permissive code libraries (MIT, Apache 2.0, BSD).
6. Commercial or restrictive sources only after explicit approval.

## Candidate source classes

- 3D: Smithsonian Open Access, NASA 3D Resources, Poly Haven, Kenney,
  Blender demo assets, Khronos glTF samples.
- Images: NASA, NOAA, Wikimedia Commons, Biodiversity Heritage Library,
  Rijksmuseum Open Data, Smithsonian Open Access, rawpixel public domain.
- Icons/SVG: Lucide, Phosphor, Tabler, Heroicons, SVG Repo only after checking
  each item's license.
- Data visualization: D3, Apache ECharts, Observable Plot, Cytoscape.js.
- Motion: Motion core, Anime.js, GSAP only if its current license fits the use.

## Review gate

An asset moves `candidate → review → approved`. The review checks authorship,
exact asset license, attribution, cultural context, technical weight, mobile
fallback, and whether modification is allowed.

Reference imagery may guide composition but is not copied or redistributed
unless its exact rights are known.
