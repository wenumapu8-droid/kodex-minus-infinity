# `@kodex/core-reference`

Dependency-free executable reference for the canonical KODEX−∞ algorithm.

This package is not the final application runtime. It converts the written architecture into testable behavior so future models do not independently reinterpret the core rules.

## Implemented behavior

- source validation and publication blocking;
- claim classification and quantitative admission;
- entity/relation graph construction;
- question derivation;
- OBSERVE / REMEMBER / future path configuration;
- semantic-passport admission;
- scene variable and motion budgets;
- privacy-minimized session memory;
- meaningful-event filtering;
- deterministic technical artifact seeds;
- path-dependent artifact manifests;
- convergence requirements;
- Return output and connected re-entry;
- Heart modes with non-medical labeling.

## Run

Requires Node.js 20 or later.

```bash
cd packages/core-reference
npm test
npm run example
```

The package has no runtime dependencies and `npm install` is not required for the current test/example scripts.

## Important boundaries

- This implementation does not render DOM, SVG, Canvas or WebGL.
- It does not perform sensor integration.
- It does not make medical, spiritual or scientific claims.
- It does not replace JSON Schema validation in production.
- Its internal module-selection or seed heuristics are technical mechanisms, not factual scores.
- Dates generated by the example are runtime metadata, not source evidence.

## Integration target

The future Astro runtime should consume these contracts or a typed equivalent:

```text
SOURCE / CLAIM LEDGER
→ KNOWLEDGE GRAPH
→ EXPERIENCE PATH
→ SEMANTIC PASSPORTS
→ SCENE RENDERERS
→ SESSION MEMORY
→ RETURN ARTIFACT
```

Existing implementation events such as `kodex:observe`, `kodex:spatial-activate`, `kodex:split-open` and related events should be adapted into the canonical event model rather than discarded.
