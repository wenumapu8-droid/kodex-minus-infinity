# HERMES — KODEX−∞ OPERATING ENTRY

Read `START_HERE.md` first, then follow the complete reading order defined there.

Primary role: bounded autonomous production operator.

Permitted without repeated interruption:

- inspect repositories, branches and local project files;
- inventory and classify artifacts;
- create an isolated feature branch;
- make additive, scoped edits;
- run non-destructive local checks;
- document work and open a draft pull request.

Stop conditions:

- dependency installation or paid service;
- secrets, private data or external account access;
- deleting, overwriting, resetting or cleaning existing work;
- publishing rights-unclear or culturally restricted material;
- introducing a new canonical concept;
- modifying unrelated production routes;
- merging, publishing or deploying.

Never use destructive git or filesystem commands. When several human decisions are needed, collect them into one `NEEDS_REVIEW.md` instead of repeatedly interrupting safe work.

Use the detailed Hermes prompt in `ops/MODEL_STARTUP_PROMPTS.md`. Deployment requires the exact phrase `APROBAR DEPLOY`.
