# ADR-0011 — SEVEN-SCENE CORRIDOR V1

Status: `CURRENT / CREATOR-DIRECTION SYNC / V1 IMPLEMENTATION AUTHORITY`  
Date: `2026-09-12`  
Supersedes for V1 implementation: `ADR-0010 — ALPHABETIC MULTIVERSE A–M–Y`

## Context

KODEX−∞ has converged from the August A–Y exploratory topology into a finite seven-scene release architecture used by the current design targets, implementation, editorial spine and production controls.

The A–Y model remains valuable historical architecture and research. It is preserved for traceability, but it is no longer the active V1 implementation topology.

This decision prevents agents from treating older alphabet documents as current runtime authority and reopening foundational architecture during production closure.

## Current V1 journey

```text
00 THRESHOLD
→ 01 PROLOGUE
→ 02 DESCENT
→ 03 ARCHIVE
→ 04 MACHINE
→ 05 COSMOLOGY
→ 06 RETURN
```

The release is finite. New foundational scenes are not added unless a verified V1 blocker demonstrates that the seven-scene architecture cannot satisfy a required function.

## Narrative topology

The corridor has a mirrored structure:

```text
THRESHOLD ↔ RETURN
PROLOGUE  ↔ COSMOLOGY
DESCENT   ↔ MACHINE
ARCHIVE   = inversion axis
```

The first half moves from exterior appearance toward memory and transformation. The second half externalizes, computes and reconnects what the journey accumulated.

`RETURN` does not restore the original starting condition. It produces a transformed return — `THRESHOLD′` — carrying memory of the route.

## Scene roles

### 00 THRESHOLD

Consent, voluntary entry, initial orientation and first memory event. The gate does not open merely because time passes. Entry is a committed action.

### 01 PROLOGUE

Recognition and observation. The system begins to respond to the observer and establishes perception as an active relation rather than passive viewing.

### 02 DESCENT

Depth, dissolution and embodied passage. Interaction changes depth/state; the scene is not conventional document scroll.

### 03 ARCHIVE

Memory, trace, record, lineage and provenance. ARCHIVE is the inversion axis: what has been experienced becomes inspectable relation.

### 04 MACHINE

Rules, computation, generative behavior and causal transformation. Parameters must produce real visible consequences; decorative pseudo-telemetry is not evidence.

### 05 COSMOLOGY

Scale, relation, topology and the expansion from local trace toward larger systems. Spatial behavior must remain authored and semantically connected to prior scenes.

### 06 RETURN

Integration and transformed continuity. RETURN synthesizes route memory into a bounded path-dependent artifact and moves toward the open-white state without claiming final truth.

## Memory law

The release must preserve a privacy-minimized event trace across the seven scenes.

A meaningful decision is canonical only if it changes at least one later property: content, available interaction, visual state, motion/sonic response, memory echo, return artifact or re-entry state.

Passive pointer movement or dwell alone must not infer consequential identity, emotion, readiness, spiritual attainment or personal meaning.

## Interaction law

The main experience uses fixed/fullscreen scene compositions. Input may include pointer, touch, keyboard, wheel/drag-as-tool, optional audio and explicit controls, but interaction must be causal and accessible.

Every essential interaction requires:

- keyboard or non-pointer equivalent;
- touch behavior;
- reduced-motion behavior;
- non-WebGL fallback where WebGL carries essential experience;
- safe exit or reversibility appropriate to the interaction.

## Visual authority

For V1 scene composition, the current creator-approved/creator-directed Hi-Fi scene targets and the latest explicit Ocín decisions outrank historical prototypes.

Historical prototypes remain a recovery library. Reuse is encouraged where a prior implementation already proves interaction, motion, audio, fallback or responsive behavior, but it must be reconciled against current scene targets rather than promoted automatically.

## Epistemic law

This ADR changes experience architecture only. It does not relax the epistemic standard.

Science, cultural material, testimony, speculation, mythopoetic content and generated atmosphere remain distinguishable. No pseudo-metric, fabricated measurement or unsourced historical/cultural claim becomes valid because it appears inside a scene.

## Relationship to A–Y

`ADR-0010` and `data/alphabet-topology.json` are retained as `DEPRECATED / HISTORICAL ARCHITECTURE` for provenance and possible future research.

For V1:

- agents must not assign or implement A–Y coordinates as current scene authority;
- A–Y does not override the seven-scene Scene Bible or current Hi-Fi targets;
- no work item may reopen A–Y unless Ocín explicitly promotes it again in a later decision;
- useful concepts from the old model may survive only when they map cleanly into current scenes without creating a parallel runtime topology.

## Definition of implementation progress

Production states are distinct:

```text
CONCEPT
→ REFERENCE
→ GENERATED ASSET
→ PROTOTYPE
→ IMPLEMENTED
→ TESTED
→ CREATOR-APPROVED
→ DEPLOYED
→ COMMERCIAL RESULT
```

No later state is implied by an earlier one.

## V1 closure gate

The seven-scene web release is not closed until:

1. each scene matches its current visual/canonical target;
2. cross-scene memory produces later consequences;
3. RETURN produces a route-dependent result;
4. required viewport QA passes at `390×844`, `430×932`, `768×1024`, `1440×900` and `1920×1080`;
5. functional, motion, accessibility and performance gates pass or have an explicitly accepted exception;
6. provenance and epistemic boundaries remain inspectable;
7. Ocín gives the required scene/release approval.
