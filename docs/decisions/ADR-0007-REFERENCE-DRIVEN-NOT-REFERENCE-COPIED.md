# ADR-0007 — Reference-driven, not reference-copied

Status: `ACCEPTED`

Date: `2026-08-06`

## Decision

External references such as Photism, `(W)HOLE`, interactive studios, UI libraries and audiovisual applications are research inputs—not templates.

KODEX may adopt:

- interaction logic;
- onboarding clarity;
- state-transition patterns;
- performance techniques;
- accessibility solutions;
- information hierarchy;
- navigation mechanics;
- audio/visual synchronization methods.

KODEX must not copy:

- brand identity;
- proprietary artwork;
- distinctive screen compositions;
- text;
- voices;
- sound recordings;
- logos;
- undisclosed code;
- a reference's visual skin as the KODEX design system.

## Required method

```text
CAPTURE EVIDENCE
→ IDENTIFY USER PROBLEM
→ ABSTRACT INTERACTION LOGIC
→ MAP TO KODEX SEMANTIC ROLE
→ CREATE INTERACTION PASSPORT
→ IMPLEMENT WITH KODEX ASSETS AND TOKENS
→ TEST OR REJECT
```

## Consequence

A reference can trigger a KODEX improvement only when the borrowed logic has:

- a named purpose;
- a later product consequence;
- accessible alternatives;
- evidence that it works in context;
- a clear copyright boundary.

Aesthetic admiration alone does not authorize implementation.
