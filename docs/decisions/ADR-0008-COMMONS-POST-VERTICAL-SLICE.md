# ADR-0008 — THE COMMONS follows the personal vertical slice

Status: `ACCEPTED`

Date: `2026-08-06`

## Decision

THE COMMONS remains canonical but is implemented after the personal journey works end to end.

Delivery order:

```text
personal path
→ Return artifact
→ source and limitation access
→ optional Commons prototype
```

## Reason

The wall introduces moderation, privacy, database, abuse, reporting and withdrawal requirements. Building it first would delay proof of the central KODEX product: a meaningful path through real art, information, interaction and memory.

## V0 consequence

The first reviewable build may include a non-networked Commons visual prototype with mocked approved entries, but it must not accept or publish real public content.

## Production prerequisite

Real public submissions require:

- policy review;
- moderation workflow;
- rate limits;
- report and withdrawal paths;
- privacy review;
- database/provider decision;
- outage behavior;
- release authorization.
