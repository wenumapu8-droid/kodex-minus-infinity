# KODEX−∞ REJECTED AND CONSTRAINED DIRECTIONS

Status: `CANONICAL GUARDRAIL`

This file records directions that produced fragmentation, visual noise, unsupported claims or strategic confusion. Models must inspect it before proposing a “new” direction.

## 1. Generic cyberpunk dashboard

Rejected symptoms:

- dense permanent HUD;
- neon around every element;
- military targeting language;
- tiny unreadable metadata;
- fake system counters;
- interface occupying more space than the artwork.

Reason: it makes KODEX interchangeable with thousands of sci-fi templates and weakens information comprehension.

## 2. Seven recolored versions of one scene

Rejected symptoms:

- same central circle or grid in every chapter;
- only accent color and title change;
- identical motion timing;
- identical content density.

Reason: scene identity must derive from function, grid, information type, interaction and consequence.

## 3. Static poster pretending to be interactive

Rejected symptoms:

- full-screen PNG or GIF as the “engine”;
- invisible interaction layer over flattened artwork;
- no semantic response to input;
- no reduced-motion logic beyond stopping a GIF.

Reason: KODEX should expose actual procedural behavior, meaningful interaction and inspectable structure.

## 4. Decorative pseudo-telemetry

Rejected unless explicitly marked atmosphere:

- arbitrary checksums;
- invented frequencies;
- random timestamps;
- unsupported coordinates;
- “signal strength” percentages;
- fake latency or anomaly counts;
- meaningless waveforms;
- decorative charts.

Reason: technical typography does not make information truthful.

## 5. Spiritual ranking as measurement

Rejected:

- Hawkins-style numbers presented as objective consciousness levels;
- emotion “frequencies” presented as physical measurements;
- ranking users from low to high spiritual worth;
- competitive transcendence, ego-loss or coherence scores.

Replacement: functional adaptive states, self-report, real sensor data when available, or mythopoetic taxonomy clearly attributed.

## 6. Unattended intense breathwork

Rejected for public self-guided mode:

- hyperventilation;
- prolonged breath holds;
- escalation toward dizziness or panic;
- claims that distress proves transformation;
- hidden flicker or coercive audio.

Replacement: natural breath, optional gentle pacing, visible stop and ordinary orientation.

## 7. Generic ancestral synthesis

Rejected:

- combining symbols from unrelated peoples into a universal sacred graphic;
- claiming invented symbols are Mapuche, Indigenous or ancient;
- removing original names and territories;
- commercializing restricted material without authorization.

Replacement: attributed source study, permission status, culturally reviewed use and clearly identified KODEX-original forms.

## 8. Literal copying of references

Rejected:

- tracing another artist's composition;
- copying palettes, logos or typography;
- reproducing diagrams with new labels;
- translating another project's text and presenting it as KODEX;
- copying shader code without license and attribution review.

Replacement: analyze structural principles and transform them through KODEX's own question, corpus, grammar and visual language.

## 9. Endless concept expansion before integration

Rejected symptoms:

- dozens of portals with no working path;
- new images generated faster than they can be catalogued;
- each agent inventing another architecture;
- no corpus, provenance or user consequence;
- no product that can be demonstrated end to end.

Replacement: first vertical slice, modular engine contracts and artifact registry.

## 10. Scroll-heavy primary journey

Rejected:

- Archive Grid appearing under the hero;
- multiple scenes visible in one long page;
- competing CTAs in the first viewport;
- mobile artwork reduced to a small card;
- browser scrolling replacing scene navigation.

Replacement: persistent fullscreen shell and overlays for secondary information.

## 11. Continuous motion everywhere

Rejected:

- animated titles, metadata, CTA, barcode and navigation simultaneously;
- permanent glitch;
- every object pulsing at the same priority;
- motion that does not stop under reduced-motion settings.

Replacement: one protagonist movement, limited structural movement, micro-signals and explicit motion priority.

## 12. Darkness as moral or spiritual inferiority

Rejected: treating `−∞`, contraction, fear, guard or withdrawal as lesser human value.

Replacement: black/fragmentation as unresolved potential and functional states as contextual, adaptive and reversible.

## 13. Claims of scientific breakthrough

Rejected:

- “KODEX proves the universe is a simulation”;
- “KODEX solves string theory”;
- presenting pedagogical models as experimental discoveries;
- using scientific aesthetics to imply validation.

Replacement: exact result, controlled regime, numerical approximation, pedagogical model and philosophical speculation remain distinct.

## 15. Canva as JavaScript runtime

Rejected assumption: importing an HTML file into Canva will execute a custom JavaScript Canvas/WebGL experience.

Reason: static import and live browser runtime are different systems. Use video, image, embeddable public URL or supported app integration depending on the requirement.

## 16. MP4/H.264 as transparent delivery

Rejected assumption: standard MP4/H.264 preserves alpha transparency.

Preferred transparent animation delivery:

- PNG sequence;
- APNG;
- WebM with alpha;
- ProRes 4444 when professional video delivery is required.

Canonical interpretation: advance to a distinct new concept unless the user explicitly requests revision.
