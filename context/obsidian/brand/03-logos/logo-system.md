# Logo System

## Estado actual

- registrar aquí las versiones oficiales del logotipo cuando estén confirmadas
- si un archivo maestro existe, documentar nombre, ubicación y formato
- si todavía no está centralizado, no asumir una versión “oficial” sin validación humana

## Variantes esperadas

- logo principal
- isotipo o monograma
- versión horizontal
- versión compacta
- versión clara sobre fondo oscuro
- versión oscura sobre fondo claro
- versión de sello o marca secundaria

## Uso recomendado

- logo principal para portada, piezas madre y soportes institucionales
- marca compacta para avatar, sticker o remates de historias
- sello secundario para packaging, detalles editoriales o textura de marca

## Reglas mínimas

- no deformar proporciones
- no aplicar sombras arbitrarias
- no cambiar color fuera de la paleta base sin razón explícita
- no superponer sobre fondos muy cargados sin área de respiro
- no usar múltiples variantes del logo en una misma pieza sin motivo

## Tareas pendientes

- vincular archivos reales del logo
- definir jerarquía de variantes
- documentar tamaños mínimos recomendados
- documentar márgenes de seguridad
