# Color Palette

## Uso

Esta paleta sirve como punto de partida operativo. Debe ajustarse con muestras reales de marca cuando queden confirmadas.

## Paleta base sugerida

- `#F3EBDD` — hueso cálido
- `#D6C1A3` — arena noble
- `#B68B5A` — bronce suave
- `#6F4E37` — tierra profunda
- `#2B211B` — oscuro orgánico

## Paleta de apoyo

- `#7E8F7C` — verde mineral apagado
- `#B77B6E` — arcilla rosada
- `#C7C2B7` — gris piedra cálido

## Función por color

- hueso cálido: fondo principal limpio
- arena noble: base secundaria y bloques suaves
- bronce suave: acento editorial y detalles de lujo artesanal
- tierra profunda: titulares, contraste y estructura
- oscuro orgánico: texto fuerte, cierres, overlays y remates

## Reglas

- usar máximo 1 o 2 colores de acento por pieza
- priorizar fondos suaves con contraste legible
- evitar combinaciones demasiado frías o saturadas
- mantener coherencia entre producto, copy y textura visual
