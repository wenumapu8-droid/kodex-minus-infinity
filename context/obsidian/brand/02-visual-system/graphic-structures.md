# Graphic Structures

## Estructuras maestras

### Post único

- foto protagonista
- titular corto o frase ancla
- soporte mínimo de marca
- espacio para CTA o detalle de colección

### Carrusel

- slide 1: impacto visual + idea principal
- slides 2-4: detalle, beneficio, materialidad o relato
- slide final: CTA o cierre de colección

### Historia

- una idea por pantalla
- texto mínimo
- prioridad en ritmo y claridad
- uso de stickers, flechas o marcos solo si aportan lectura

### Banner

- jerarquía inmediata
- producto o concepto claro
- CTA legible
- composición simple y reusable

## Patrones recomendados

- marcos sutiles
- bloques de color cálido
- textura suave tipo papel, mineral o material orgánico
- recortes editoriales
- detalle macro de producto

## Evitar

- saturación de elementos
- demasiados adornos rituales sin función
- recargar texto sobre producto
- usar siempre la misma composición
