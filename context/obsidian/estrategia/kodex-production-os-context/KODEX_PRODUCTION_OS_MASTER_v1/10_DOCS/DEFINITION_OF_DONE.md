# Definition of Done

KODEX is production-ready only when:

1. All seven scenes use manifests.
2. All scene lifecycles destroy their resources.
3. Mobile has no accidental overflow.
4. Fallback and reduced motion are visually complete.
5. Balanced profile achieves stable mobile performance.
6. Every external asset has provenance.
7. Archive records validate.
8. Commercial exits work.
9. Analytics report the journey.
10. Error monitoring is active.
11. Release checklist is signed.
12. Rollback can be completed without code reconstruction.
