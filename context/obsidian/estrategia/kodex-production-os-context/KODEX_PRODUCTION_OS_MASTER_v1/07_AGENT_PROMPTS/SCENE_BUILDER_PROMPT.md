# SCENE BUILDER PROMPT

Build or revise one KODEX scene.

## Inputs

- Scene manifest.
- Hero module.
- Supporting micrographics.
- Quiet Frame before or after.
- State machine.
- Performance budgets.
- Copy lexicon.

## Required steps

1. Confirm narrative verb.
2. Define states and transitions.
3. Connect shared world state.
4. Connect hero module.
5. Define desktop composition.
6. Define independent mobile composition.
7. Add fallback.
8. Add reduced motion.
9. Add analytics.
10. Add Playwright states.
11. Record assets.
12. Validate release criteria.

## Rejection conditions

- Layout is a normal hero section.
- Mobile is desktop stacked.
- Main visual is generic.
- More than one primary action.
- Decorative telemetry without function.
- Overflow exists.
- Fallback is empty.
- Performance claim lacks real-device evidence.
