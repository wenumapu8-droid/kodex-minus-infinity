# KODEX Production OS — Context

The previous kits supplied visual assets, CRT, ASCII, Quiet Frames, sigil typography and 72 generative modules.

The missing layer was production governance.

This package adds:

1. canonical scene contracts;
2. world state;
3. lifecycle orchestration;
4. persistent memory;
5. transition control;
6. accessibility management;
7. performance measurement;
8. analytics taxonomy;
9. asset provenance;
10. archive schemas;
11. visual and interaction testing;
12. release controls.

This is the package that prevents KODEX from becoming a folder of impressive but disconnected experiments.
