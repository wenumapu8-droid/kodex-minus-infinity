# Asset and License Policy

Every external visual, font, sound, shader, texture or code fragment must enter the provenance ledger before production.

## Required fields

- asset ID;
- creator;
- source;
- license;
- commercial-use status;
- redistribution status;
- attribution;
- allowed scenes;
- cultural review;
- modification notes.

## Rules

1. Do not commit paid source packs to a public repository.
2. Do not redistribute third-party source files inside KODEX kits.
3. Store receipts and license snapshots outside the public frontend.
4. Fonts require license verification and WOFF2 optimization.
5. Indigenous-derived names and symbols require cultural classification.
6. KODEX-original brand assets are not automatically MIT because nearby code is MIT.
7. External shaders must be rewritten or attributed according to their license.
