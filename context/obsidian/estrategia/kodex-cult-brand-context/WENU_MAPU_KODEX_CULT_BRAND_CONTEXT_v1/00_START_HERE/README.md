> Wenu Mapu is the house.  
> Wültufe reads the body.  
> KODEX remembers the signal.  
> The First Circle carries the culture.

No añadir nuevos nombres, escenas, símbolos, subproductos o iniciativas sin verificar si ya existe una función equivalente. La prioridad es consolidar, no acumular universos paralelos.
