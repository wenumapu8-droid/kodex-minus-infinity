# KODEX−∞ AS MEMORY INFRASTRUCTURE

KODEX−∞ no es solo experiencia visual. Es la infraestructura cultural y de procedencia de Wenu Mapu.

Debe registrar objetos, materiales, makers, ediciones, constelaciones, portadores, sesiones, retornos, reparaciones, señales y capítulos.

## Registro de objeto

```text
KDX-OBJ-00471
ARCHIVE AR-03
MATERIAL ATACAMA METEORITE
MAKER OCIN
EDITION 1/1
STATUS CARRIED
CONSTELLATION C-118
```

## Registro de constelación

Mapa anatómico, lado, ubicaciones, piezas, fechas, materiales, curación, fotografías, recomendaciones y próximos nodos.

## Memoria del usuario

```text
FIRST ENTRY       SOURCE UNKNOWN
AFTER ORACLE      SYMBOL IDENTIFIED
AFTER EAR MAP     CONSTELLATION RECORDED
AFTER PURCHASE    OBJECT CARRIED
AFTER RETURN      MEMORY ACTIVE
```

## Artefacto de sesión

SVG, PNG, checksum, mapa, seed, constellation ID, dominant symbol, phrase, timestamp y scene trail.

## Estados del archivo

LATENT, DETECTED, MAPPED, FORGED, CARRIED, RETURNED, REPAIRED, ARCHIVED y TRANSMITTED.

## Política técnica

- No depender solo de WebGL.
- Mantener fallback.
- Rutas compartibles.
- Datos reales separados de telemetría decorativa.
- Códigos consistentes.
- Información sensible del cliente nunca pública.
