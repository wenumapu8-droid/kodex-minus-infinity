# KODEX−∞ QUIET FRAMES / ARCHIVE INTERLUDES
## Context + Components Package v1

Este paquete convierte la idea de “páginas pulmón” en un subsistema reutilizable para KODEX−∞.

## Objetivo

Crear descansos visuales entre escenas densas mediante composiciones editoriales silenciosas:

- mucho vacío;
- una sola imagen o símbolo;
- geometría blanca mínima;
- microcódigos verticales;
- monocromo;
- motion casi imperceptible;
- cero HUD innecesario.

## Principio rector

> Dense scenes create intensity. Quiet frames create authority.

## Regla de composición

- 70% vacío
- 20% imagen o símbolo
- 8% geometría
- 2% microcódigo

## No hacer

- convertir el interludio en otra escena HUD;
- usar glitch constante;
- añadir múltiples CTAs;
- apilar desktop en mobile;
- repetir barcodes, radars y telemetry solo para llenar.
