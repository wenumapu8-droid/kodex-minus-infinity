# KODEX QUIET FRAMES — MASTER CONTEXT

## 1. Definición

Quiet Frames, también llamados Archive Interludes, son páginas de respiración editorial dentro de KODEX−∞.

No son:

- landing pages;
- slides promocionales;
- loaders;
- páginas de contenido largas;
- dashboards;
- escenas hero completas.

Son pausas visuales con identidad KODEX.

## 2. Función narrativa

Un Quiet Frame puede:

- cerrar una escena;
- abrir un capítulo;
- cambiar de ritmo;
- conectar lo digital con lo material;
- introducir una doctrina;
- preparar una transición;
- permitir que el usuario procese lo anterior;
- generar tensión antes de una escena intensa.

## 3. Lenguaje base

Cada composición debe usar:

- fondo negro obsidiana;
- una imagen o símbolo principal;
- blanco hueso;
- máximo un acento tenue;
- geometría modular;
- microtipografía;
- retícula fantasma;
- grano y scanline suaves;
- motion mínimo.

## 4. Anatomía

1. Background field
2. Image or symbol chamber
3. One geometric intervention
4. Vertical code rail
5. Microcaption
6. Ghost axis or registration line
7. Optional subtle motion
8. Persistent exit or next command only when required

## 5. Jerarquía

1. masa visual principal;
2. vacío;
3. intervención geométrica;
4. código;
5. microcopy;
6. navegación.

## 6. Composición

La pieza debe sentirse recortada, no decorada.

La imagen debe aparecer como:

- fragmento;
- scan;
- expediente;
- muestra;
- fotografía encontrada;
- textura de campo;
- placa material;
- archivo incompleto.

## 7. Tipos canónicos

### IMAGE INTERLUDE
Imagen monocroma + bracket + código.

### SYMBOL INTERLUDE
Sello o glyph grande + vacío.

### MATERIAL INTERLUDE
Macro de materia, metal, piedra, piel o superficie.

### FIELD NOTE INTERLUDE
Microtexto + pequeño fragmento visual.

### THRESHOLD SHEET
Página casi tipográfica usada antes de una transición.

### CONSTELLATION PLATE
Imagen mínima + coordenadas + marcas.

## 8. Reglas de motion

Permitido:

- fade lento;
- mask reveal;
- drift de 1–3 px;
- scanline suave;
- flicker breve;
- pulse casi invisible;
- parpadeo de cursor;
- desplazamiento de código.

No permitido:

- zoom dramático;
- glitch constante;
- órbitas rápidas;
- varias capas moviéndose a la vez;
- bloom fuerte;
- parallax agresivo.

## 9. Responsive

Desktop:

- composición asimétrica;
- imagen contenida;
- rail lateral;
- mucho vacío.

Mobile:

- una sola columna;
- imagen 34–44dvh;
- códigos compactos;
- navegación dentro de safe-area;
- cero overflow;
- no conservar rails fuera del viewport.

## 10. Objetivo estético

La pieza debe sentirse:

- editorial;
- museal;
- silenciosa;
- precisa;
- tecnológica;
- archivística;
- musical;
- sobria;
- segura.

## 11. Regla crítica

Quiet Frames no compiten con las escenas principales. Las hacen más fuertes.
