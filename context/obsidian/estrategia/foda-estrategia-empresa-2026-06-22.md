# Wenu Mapu — FODA, estrategia y empresa-de-uno con IA (2026-06-22)
> Visión de Ocin: que parezca un equipo de muchos, pero es 1 persona + IA. Operar como compañía completa.
> Documento vivo de estrategia. Honesto, específico de Wenu (no genérico).

## 1. La tesis de negocio
Marca de joyería corporal ritual, raíz mapuche, **stock limitado y alto contacto**. Ventaja: alma/significado real (no fast-fashion). Modelo: **dos funnels** — joya (repetición, viaje de gauge, ingreso recurrente) + arte/autor (pieza única, ticket alto, deseo). Diferenciador defendible: profundidad cultural + oficio (fundador piercer APP-trained + diseñador industrial). Operación: 1 persona apalancada en agentes IA = "empresa de uno".

## 2. FODA

### Fortalezas (F)
- Identidad y relato únicos (cosmología mapuche, Wallmapu, historia del fundador) — imposible de copiar.
- Oficio real + credenciales (APP, orfebrería, platería mapuche).
- Nicho con comunidad fiel (body jewelry / stretching).
- Catálogo propio ya cargado (~195 SKU en NocoDB) con datos estructurados.
- Apalancamiento IA: agentes de diseño, catálogo, QA, loops diarios → produce como equipo.
- Materiales nobles + meteorito Atacama (storytelling premium).

### Debilidades (D)
- Bandwidth de 1 persona (cuello de botella humano).
- Cobertura de fotos incompleta (en proceso) — muchos productos sin macro propia.
- Datos de catálogo "gruesos" (Expansion/Mixed) — refinándose.
- Checkout en WordPress legacy (hybrid) — fricción y deuda técnica.
- Dependencia de llaves/créditos de IA (Hermes hoy caído por cuota).
- Sin prueba social / reviews visibles aún.
- Tienda nueva no en el dominio (falta cutover).

### Oportunidades (O)
- **CRM ritual / personalización** (perfil por cliente desde compra → ofertas por gauge/gusto). Ver `10-Proyectos/concepto-crm-ritual-personalizado`.
- **Calendario ritual vivo** (We Tripantu, solsticios) → contenido que renueva + SEO + comunidad.
- **Funnel de arte** como imán top-of-funnel y ticket alto.
- **Servicio de piercing** (citas Truckee) como ingreso + trust local + captación.
- **SEO/contenido** vía cosmología y guías de oficio (calibres, aftercare) — autoridad de nicho.
- **Wholesale / stockists / pop-ups** (escala B2B sin perder alma).
- **Automatización**: cada proceso repetitivo → agente (fotos, copy, QA, social, email).

### Amenazas (A)
- Competidores con mejor maquinaria comercial (TAWAPA, Diablo, marketplaces).
- Dependencia de plataformas (WooCommerce, Cloudflare, APIs de IA).
- Riesgo de 1 sola persona (salud, tiempo, foco).
- Cambios de algoritmo/redes para captación.
- Falsificación de procedencia (meteorito) → defender con certificados.

## 3. Estructura "empresa de uno" (roles → IA/automatización)
| Departamento | Quién/Cómo | Estado |
|---|---|---|
| Dirección / estrategia | Yo (orquestador) | activo |
| Diseño / UX / frontend | Agente "Design QA + fixes" | activo |
| Catálogo / fotos / datos | Agente "Inventario visual" + granito diario | activo |
| QA / testing | Agente "QA camino de compra" | activo |
| Mejora continua | Loop diario de mejora (prototipos) | automático 9:32 |
| Ops / comunicación / social | **Hermes** (cuando se recarguen llaves) | pendiente recarga |
| Marca / canon | Docs brand/ + voz canónica | activo |
| Finanzas / proyecciones | Framework abajo (necesita tus números) | parcial |

→ Esto es lo que hace que "parezcan muchos": cada función es un agente con su misión, reportando a una dirección. Hermes suma como brazo de ops/automatización autónoma una vez recargado.

## 4. Escalabilidad
Palancas para crecer SIN romper el modelo (alma + stock limitado):
1. **Producto**: subir cobertura de fotos/datos al 100% → más SKU vendibles bien presentados.
2. **Conversión**: PDP transaccional + trust + carrito nativo (Woo Store API) → más % de compra.
3. **Retención**: CRM ritual + email por gauge journey → recompra (la palanca más barata).
4. **Captación**: contenido (calendario ritual, guías), servicio de piercing, IG/TikTok → tráfico.
5. **Canales**: wholesale/stockists para volumen B2B; arte para ticket alto.
6. **Automatización**: cada proceso manual → agente, para que el crecimiento no dependa de más horas tuyas.

## 5. Proyecciones — framework (necesito tus números reales)
Para proyectar de verdad necesito de vos/NocoDB/Woo:
- Ventas últimos 3–6 meses (unidades + $), ticket promedio (AOV), tasa de conversión, tráfico mensual, costo por pieza, margen, recompra %.
Con eso modelo 3 escenarios (conservador/base/optimista) con las palancas de §4. Sin esos datos no invento números — te dejo el modelo listo para llenar.

## 6. Próximos pasos sugeridos (orden de impacto)
1. Cerrar QA del camino de compra → confirmar que se vende (en curso).
2. Cutover verificado al dominio.
3. Subir cobertura de fotos/datos (granito + tandas).
4. Trust/reviews + PDP transaccional.
5. Activar CRM ritual (cuando el funnel madure).
6. Recargar Hermes → sumarlo como ops/automatización.
