# Métricas y metodología — el tablero que cierra el loop

> Sin medición, el motor corre a ciegas. Esto define QUÉ medir, CON QUÉ, y CÓMO decidir.
> Ligado a [[PLAN-MAESTRO-MARKETING-2026-07-28]].

## Las metodologías que usamos (las mejores, aplicadas a vos)

1. **North Star Metric (una sola estrella).** No perseguir 20 números. UNA métrica que resume
   valor real. Para vos: **reservas de cita** (la acción que ES el negocio). Indicador
   adelantado: **registros de email** (predicen reservas futuras).
2. **AARRR / Pirate Funnel** — las 5 etapas, cada una con su métrica:
   - **Acquisition** (llegan): visitas al sitio desde contenido/Pinterest/referidos.
   - **Activation** (primer valor): descargan el arte / usan Design Your Ear / dejan email.
   - **Retention** (vuelven): abren emails, vuelven al sitio, clientes que repiten.
   - **Referral** (traen a otros): clientes que refieren, contenido compartido.
   - **Revenue** (pagan): reservas + ventas.
3. **Growth loop, no embudo lineal.** Contenido → email → cliente → referido/testimonio →
   más contenido. El output de un ciclo alimenta el input del siguiente. Diseñar para que gire.
4. **Leading vs lagging.** Email signups y guardados = adelantados (mueven hoy). Reservas y
   ventas = atrasados (resultado). Optimizar los adelantados para mover los atrasados.
5. **RICE para priorizar apuestas de contenido** (Reach × Impact × Confidence ÷ Effort).
   Cuando dudes qué tema/formato hacer, el que gane RICE.
6. **Cohortes / LTV.** No solo "cuántos clientes" sino "cuánto vale un cliente en el tiempo"
   (repite? refiere?). Tu modelo premium vive de LTV alto, no de volumen.

## El stack de métricas (todo lo disponible, por fuente)

| Fuente | Qué mide | KPIs a mirar |
|---|---|---|
| **GA4** | tráfico + eventos del sitio | sesiones, origen, uso de Design Your Ear, clics a producto, inicios de reserva |
| **Search Console** | SEO | queries que te encuentran, impresiones, CTR, posición |
| **Email (MailerLite)** | lista + envíos | nuevos suscriptores (⭐ adelantado), open/click, email→reserva |
| **Pinterest analytics** | descubrimiento | impresiones, guardados, clics salientes al sitio |
| **IG/TikTok** | descubrimiento | **guardados por cada 1.000 vistas** (no likes), clics a bio/sitio |
| **Booking / calendario** | el negocio | reservas de cita (⭐ North Star), no-shows |
| **WooCommerce** | ventas | pedidos, ticket promedio, productos que venden |

Eventos GA4 clave a instrumentar: `download_art`, `start_design_your_ear`, `submit_email`,
`begin_booking`, `book_appointment`, `product_click`. Con eso el loop tiene datos reales.

## El tablero y la cadencia (el loop en acción)

- **Semanal (5 min):** suscriptores nuevos, tráfico del contenido de la semana, guardados/1000,
  inicios de reserva. ¿Qué pieza tiró más? Se anota.
- **Mensual (la revisión de aprendizaje):** North Star (reservas) + funnel completo. Qué TEMA,
  qué HISTORIA madre y qué GATILLO trajeron reservas. Duplicar lo que funciona, matar lo débil,
  actualizar el banco de temas + el plan + la memoria. Cada mes el sistema arranca más afilado.

Regla: **los likes son aplausos; las reservas y los emails son negocio.** No decidir por vanity.

## La verdad de asesor (importante)

El plan está completo y maduro. **A partir de acá, cada hora de más estrategia rinde menos que
una hora de ejecución.** El valor real ahora se genera cuando: (1) Ocin filma y publica, (2) se
implementa la web "cita-primero", (3) entran los datos y el loop empieza a aprender. Tenemos el
motor; falta encenderlo con combustible real. No más planes por un tiempo — a shippear y medir.
