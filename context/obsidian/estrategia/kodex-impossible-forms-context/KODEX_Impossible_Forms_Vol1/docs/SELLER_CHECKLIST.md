# Seller Checklist

- Replace `[RIGHTS HOLDER]` in the buyer license.
- Add the seller name, support email, refund policy and support period.
- Decide whether the listing includes rendered loops only or source files.
- Test all MP4, GIF and HTML files on Android, iOS, macOS and Windows.
- Review the marketplace’s own licensing rules before publishing.
- Do not advertise worldwide legal clearance or exclusivity without legal review.
- Use `branding/product-cover.jpg` as the main listing image.
- Use `branding/contact-sheet.jpg` to show the full collection.

## Suggested editions

**Rendered Edition** — GIF, MP4, posters and thumbnails.

**Creator Edition** — Rendered Edition plus source and web gallery.

**Extended Edition** — broader installation/client rights under a separately
reviewed license.
