# KODEX Impossible Forms — Vol. 1

A commercial-ready procedural motion pack with twelve original impossible forms.

## Included

- 12 looping GIF previews, 320×320.
- 12 H.264 MP4 loops, 320×320.
- 12 PNG posters and 12 JPG thumbnails.
- Responsive web gallery for mobile and desktop.
- One standalone web page per loop.
- Python equations for the core generative families.
- JavaScript loop-player utility.
- JSON and CSV preset manifests.
- Product cover, contact sheet, listing copy and commercial-license template.

No external image, video, audio, texture or font file is bundled.

## Open the gallery

Open `web/index.html`.

When the browser blocks local paths, run from the product folder:

```bash
python3 -m http.server 8080
```

Then open:

```text
http://localhost:8080/web/
```

## Technical scope

The rendered loops are final distributable assets. The source folder includes the
mathematical curve generators and web playback utilities. It is not a KodeLife
project file and does not include third-party shaders.
