# KODEX MODULAR SIGIL TYPE SYSTEM v1

A complete context-and-code kit for rectangular modular typography, sigil-like display lettering and Quiet Frame mood presets.

## Included

- Original 5×7 SVG modular alphabet: A–Z, 0–9 and core punctuation.
- Four render styles: Block, Ritual, Signal and Outline.
- Astro component.
- JavaScript renderer.
- KODEX symbol sprite.
- Type hierarchy and font pairing strategy.
- Original eight Quiet Frame presets.
- Four additional mood presets: Indie Deep, Chill Out, Dark Ambient and Ritual Dub.
- 12-preset merged manifest.
- Demo and SVG preview.
- Agent prompts, schemas and QA.

## Open the demo

```bash
cd KODEX_MODULAR_SIGIL_TYPE_SYSTEM_v1
python3 -m http.server 8080
```

Then open:

```text
http://localhost:8080/06_DEMO/
```

## Important

No font binaries are included. External font families must be installed from their official sources or npm packages. The KDX Sigil Grid itself is generated as SVG geometry.
