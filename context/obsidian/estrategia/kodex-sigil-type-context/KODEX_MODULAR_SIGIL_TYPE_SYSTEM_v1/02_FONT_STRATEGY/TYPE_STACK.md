# TYPOGRAPHY STACK

## Recommended production stack

### Hero / readable geometry
**Oxanium** — square and futuristic; best for large scene titles and commands.

### Secondary geometric voice
**Chakra Petch** — square sans with tapered corners; useful for labels, cards and quieter chapter titles.

### Interface
**Geist Mono** or **IBM Plex Mono** — codes, telemetry, archive IDs and vertical rails.

### Editorial
**Geist Sans** — restrained narrative copy and captions.

### Custom signature
**KDX Sigil Grid** — original SVG alphabet included in this kit.

## Suggested assignments

```css
--font-hero: "Oxanium", sans-serif;
--font-interface: "Geist Mono", "IBM Plex Mono", monospace;
--font-editorial: "Geist", sans-serif;
--font-sigil: SVG renderer, not a normal font-family;
```

## Why not use Orbitron everywhere?

Orbitron is useful as an accent, but broad use can push KODEX toward generic sci-fi or gaming. Reserve it for Threshold, transmission plates or very short commands.
