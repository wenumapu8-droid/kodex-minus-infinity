# OPEN-FONT INSTALLATION OPTIONS

No font binaries are included in this ZIP.

## npm

```bash
npm i geist @fontsource/ibm-plex-mono @fontsource/chakra-petch @fontsource-variable/oxanium @fontsource-variable/orbitron
```

Example imports:

```ts
import 'geist/font.css';
import '@fontsource/ibm-plex-mono/400.css';
import '@fontsource/chakra-petch/600.css';
import '@fontsource-variable/oxanium';
```

Check each package and license before production bundling. The recommended families are open-source under the SIL Open Font License in their official repositories.
