# HOW TO CONSTRUCT NEW SIGIL GLYPHS

## Grid

Use a 5×7 base grid. Each active cell is a module.

## Module rules

- Block: full square.
- Ritual: cut-corner octagon.
- Signal: horizontal slit.
- Outline: technical cell outline.

## Character rules

1. Maintain recognizability at 24 px height.
2. Keep at least one continuous vertical or horizontal spine.
3. Use no more than one intentional break per glyph.
4. Mirror only when the Latin character remains identifiable.
5. Never claim an invented glyph is traditional Mapuche writing.
6. Special symbols must be cataloged separately from alphabetic characters.

## Signature ligatures to design later

- KD
- DX
- KDX
- AR
- ND
- PR
- ∞ integrated with KODEX

Build these as SVG symbols, not automatic substitutions inside body text.
