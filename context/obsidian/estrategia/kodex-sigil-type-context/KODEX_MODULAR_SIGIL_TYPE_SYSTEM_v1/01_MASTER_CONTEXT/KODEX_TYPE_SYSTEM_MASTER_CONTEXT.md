# KODEX MODULAR SIGIL TYPE SYSTEM — MASTER CONTEXT

## Purpose

Create a typographic layer that feels rectangular, modular, coded and ritual without becoming an unreadable novelty font.

## System architecture

1. **KDX Sigil Grid** — original SVG modular alphabet for hero words, seals, chapter codes and transitions.
2. **Square display family** — Oxanium or Chakra Petch for readable titles.
3. **Interface mono** — Geist Mono or IBM Plex Mono for codes and metadata.
4. **Editorial sans** — Geist for sparse narrative text.

## Rule

The sigil alphabet is a display instrument, not body text.

Use it for:
- KODEX
- NODE names
- chapter numbers
- 1–3 word commands
- seals
- artifact IDs
- scene transitions

Do not use it for:
- paragraphs
- accessibility labels
- product descriptions
- legal text
- long navigation labels

## Visual grammar

- rectangular modules;
- 5×7 grid;
- deliberate gaps;
- cut corners;
- incomplete strokes;
- one anomaly maximum per word;
- controlled asymmetry;
- no pseudo-Mapuche glyph claims;
- no random occult marks.

## Styles

### BLOCK
Hard modules, strongest impact.

### RITUAL
Cut-corner cells, seal-like and ceremonial.

### SIGNAL
Compressed horizontal cells, suited to transmission and music.

### OUTLINE
Technical diagram mode, quiet and precise.

## Pairing

- Hero sigil + Oxanium display + Geist Mono code.
- Quiet frame sigil + Geist editorial + IBM Plex Mono metadata.
- Never pair more than three typographic voices in one viewport.

## 12 presets

The package contains the original eight Quiet Frame presets plus four mood-based variants:
- Indie Deep
- Chill Out
- Dark Ambient
- Ritual Dub

The mood names describe rhythm, density and motion—not literal music genres that must be played.
