# PLAN MAESTRO — Sistema de marketing automatizado Wenu Mapu

> Documento canónico. Todo lo de marketing cuelga de acá. Es un SISTEMA VIVO: cada mes
> aprende de los datos y se actualiza para aumentar la probabilidad de éxito. Índice al pie.

## Norte

$10.000/mes de forma orgánica para que Ocin viva de su arte y deje el trabajo sobre-calificado.
Horizonte honesto: 12–24 meses. Identidad: **underground, bajo cita, la web ES el negocio.**
Cuello de botella real: **descubrimiento**. Modelo: profundidad, no masas — ~400–600 true fans.

## El sistema (4 capas)

1. **Posicionamiento** — la web = columna vertebral = la CITA. Todo el sitio funnel a reservar.
   → [[auditoria-posicionamiento-web-2026-07-28]]
2. **Motor de contenido** — skill `wenu-editorial`: 1 tema central/semana → reel + carrusel +
   journal + email + captions + shotlist + CTA. 4 territorios (Piercing Intelligence 35%,
   Objetos/proceso 25%, Archivo neoancestral 20%, Portal/tech 20%). → [[kit-despegue-semana-01-2026-07-28]]
3. **Distribución** — skill `wenu-distribuir`: Pinterest, email, IG/TikTok, blog, Etsy, GitHub,
   deploy seguro. Crear una vez, distribuir en todo. → [[kodex-distribucion-multiplataforma-2026-07-27]]
4. **Medición + aprendizaje** — GA4 + Search Console + el loop (abajo).

## Ritmo automatizado (semanal)

- **Lunes:** `wenu-editorial` genera el paquete de la semana. Ocin lo revisa (dirección/cultura).
- **Ocin filma** 3 clips de proceso (su parte irremplazable).
- **Se distribuye:** pines Pinterest + reel/TikTok + email de nurture + post de blog (repurpose del mismo tema).
- **Deploy** de cambios de sitio (serializado, sin romper la joyería).
- **Se registran** los KPIs de la semana.

## EL LOOP DE APRENDIZAJE (lo que hace que crezca constantemente)

Cada mes (revisión que se guarda en este segundo cerebro):
1. Leer métricas reales (GA4, Search Console, registros de email, reservas).
2. Identificar qué TEMAS y FORMATOS trajeron reservas + emails (no likes).
3. **Duplicar** lo que funciona, **matar** lo débil, actualizar el banco de temas.
4. Actualizar este plan + la memoria del agente con lo aprendido.
5. El siguiente ciclo arranca más afilado. Así cada mes sube la probabilidad de éxito.

Verdad honesta: la automatización escala investigación, estructura y distribución. Pero **el
alma (los videos, las manos, las decisiones culturales) y los DATOS (que solo llegan si se
publica de verdad) son de Ocin.** Sin ese input humano, el loop no aprende. No hay atajo.
