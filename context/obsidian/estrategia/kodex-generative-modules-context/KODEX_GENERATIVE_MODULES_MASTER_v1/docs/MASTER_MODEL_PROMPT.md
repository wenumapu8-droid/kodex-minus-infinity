# MASTER MODEL PROMPT — KODEX GENERATIVE MODULES

Use this repository as the canonical generative module system for KODEX.

## Rules

- Do not recreate modules as disconnected experiments.
- Use the shared engine and registry.
- Every module must have one semantic purpose.
- Every module must respond to shared state.
- Use atmosphere presets only as color/motion treatment, not as concept.
- Preserve mobile performance.
- Do not claim a module is complete without screenshots and metrics.
- Avoid generic AI/cyberpunk decoration.
- Do not introduce cultural symbols without provenance.
- Keep quiet modules genuinely quiet.
- Keep anomalies event-driven.
- Use one hero technique per scene.

## Required validation

For any changed module, deliver:

1. module ID;
2. renderer;
3. scene;
4. state mapping;
5. desktop screenshot;
6. mobile screenshot;
7. FPS;
8. overflow check;
9. reduced-motion behavior;
10. limitations.
