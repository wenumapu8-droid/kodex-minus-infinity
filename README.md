# KODEX−∞

**Living Information Design · Generative Archive · Contemplative Interface**

KODEX−∞ is a living information system that transforms evidence, memory, culture, symbols and human experience into explorable, generative and interactive structures.

> Information is not displayed. It is embodied.
>
> The archive does not store. It remembers.
>
> Every path preserves memory. Every convergence changes the observer.

## Experience invariant

```text
−∞ / BLACK / FRAGMENTATION
        ↓
THRESHOLD
        ↓
USER DECISIONS + UNIQUE PATH
        ↓
ARCHIVE / MACHINE / HEART / COSMOLOGY
        ↓
RETURN / +∞
        ↓
WHITE + PURE SPECTRAL COLOR
        ↓
REFLECTION / CONTRIBUTION / SHARING / RE-ENTRY
```

`RETURN / +∞` is not a decorative ending or redirect. It is the semantic convergence of the path: memory becomes visible, provenance becomes inspectable, relations become legible, a path-dependent artifact emerges, and another route opens.

## Non-negotiable rules

- Work on a branch and submit a pull request.
- Never create parallel canon silently.
- Never fabricate data, biometrics, frequencies, citations or cultural authority.
- Keep evidence, interpretation, speculation, myth and atmosphere visibly distinct.
- Preserve attribution, rights status, territory and permission requirements.
- Keep private conversations, personal data and restricted knowledge outside this public repository.
- No deployment occurs without the exact phrase `APROBAR DEPLOY`.
